# 🍽️ Receitaí

Aplicativo de receitas desenvolvido em React, criado com o objetivo de facilitar a busca, visualização e organização de receitas culinárias.

## 📱 Sobre o projeto

O Receitaí é um aplicativo desenvolvido para oferecer uma experiência simples e intuitiva para pessoas que gostam de cozinhar e descobrir novas receitas.

O projeto conta com diferentes telas e funcionalidades, permitindo que o usuário navegue pelo aplicativo, encontre receitas e visualize seus detalhes.

## ✨ Funcionalidades

- 🔐 Tela de Login
- 📝 Tela de Cadastro
- 🏠 Tela Inicial (Home)
- 🍲 Lista de receitas
- 🔎 Visualização de detalhes das receitas
- ❤️ Sistema de favoritos
- 💡 Dicas culinárias
- 🧭 Navegação entre as telas
- 📱 Interface adaptada para diferentes tamanhos de tela

## 🛠️ Tecnologias utilizadas

- CSS
